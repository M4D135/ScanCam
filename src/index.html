Aide à la lecture

01

Format

Un code carré peut être un Data Matrix. Dans Réglages → Lecture, choisissez Tous les formats en cas de doute.

02

Viser et déclencher

En Manuel, gardez le code entier dans le cadre central, puis appuyez sur Scanner. En Auto, la lecture est continue.

03

Caméra et lampe

Le bouton Lampe utilise l’éclairage de la caméra lorsqu’il est disponible. Dans Réglages, ajustez la mise au point ou l’exposition selon votre matériel.

04

Code difficile

Dans Réglages → Lecture, essayez le profil Précision, isolez l’étiquette avec la zone centrale ou importez une photo plus nette.
